# Dependency Graph Visualizer

## 1. Общее описание
Инструмент для визуализации графа зависимостей менеджера пакетов. 
На данном этапе (Этап 1) реализован минимальный прототип CLI-приложения, 
который считывает настраиваемые пользователем параметры из конфигурационного 
файла формата CSV и выводит их в консоль в формате ключ-значение. 
Реализована обработка ошибок невалидных параметров.

## 2. Описание настроек
### Настраиваемые параметры (читаются из CSV):
- `packageName` — Имя анализируемого пакета.
- `path` — URL-адрес репозитория или путь к файлу тестового репозитория.
- `mode` — Режим работы(0 - работа с URL, 1 - работа с каталогом репозитория)
- `packageVersion` — Версия пакета.



## 3. Команды для сборки и запуска тестов
Проект не требует сложной сборки, используется стандартный интерпретатор Python.

**Запуск приложения:**
```bash
python src/main.py --path config.csv
